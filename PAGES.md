# Available Pages

This POEMs prototype includes the following pages:

## Main Pages

- [Dashboard](http://localhost:5173/) - Main dashboard view
- [My Funds](http://localhost:5173/my-funds) - Fund management and tracking
- [Unifund Registry](http://localhost:5173/unifund-registry) - Registry of unifunds with search and metrics
- [Transition Dashboard](http://localhost:5173/transition-dashboard) - Transition metrics and analytics
- [Select Interventions](http://localhost:5173/select-interventions) - Browse and select interventions
- [This Morning's Routes](http://localhost:5173/mornings-routes) - Morning delivery routes

## Worker & Opportunities

- [Opportunities](http://localhost:5173/opportunities) - View available opportunities
- [Availability](http://localhost:5173/availability) - Manage availability
- [Roles](http://localhost:5173/roles) - Role management
- [Select Workers](http://localhost:5173/select-workers) - Worker selection
- [Make Booking](http://localhost:5173/booking) - Create new booking

## Business & Market

- [Market Data](http://localhost:5173/market-data) - Market data and trends
- [Market Interventions](http://localhost:5173/interventions) - Browse market interventions
- [Create Intervention](http://localhost:5173/intervention) - Create new intervention
- [Business Pools](http://localhost:5173/pools) - Business pool management
- [Chain Builder](http://localhost:5173/chains) - Supply chain builder

## Other

- [Requirements](http://localhost:5173/requirements) - Requirements management
- [Packages](http://localhost:5173/packages) - Package management
- [Finance](http://localhost:5173/finance) - Financial overview
- [Analytics](http://localhost:5173/analytics) - Analytics dashboard
- [Search](http://localhost:5173/search) - Search functionality
- [My Checks](http://localhost:5173/my-checks) - Check management
- [Profile](http://localhost:5173/profile) - User profile

## Development

To run the development server:
```bash
npm run dev
```

Then navigate to any of the pages listed above.
